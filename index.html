Where's my ZEC?

Paste a Zcash transaction ID or address. See where the ZEC is, who has to act next, and what to send them.

Try:

Never paste a seed phrase or private key here or into any website. We never ask for one, and this page refuses them.

How it knows

Every answer carries one word for how sure it is:

ProvenThe Zcash chain's own record shows it.
ReportedA service's own records say so, for example THORChain or the Omni bridge.
InferredThe facts fit, but nothing proves it.
Not visibleA shielded step the chain doesn't show.
UnknownWe couldn't check, and we say so.

Privacy

  • We never ask for a seed phrase, private key or viewing key, and this page refuses them if pasted.
  • An address is answered on this page from a dated table. It is not sent anywhere.
  • For a transaction, only the transaction ID goes to api.blockchair.com, a public Zcash explorer.
  • If that transaction carries a THORChain swap instruction, only the transaction ID also goes to THORChain's public records at gateway.liquify.com (or midgard.ninerealms.com if that is down).
  • Only if you press "Check bridges and swaps", the transaction's public transparent output addresses go to the Omni bridge's records at mainnet.api.bridge.nearone.org.
  • Those services see your IP address, as any website does. Nothing is stored: no accounts, no history, no cookies, no analytics.
